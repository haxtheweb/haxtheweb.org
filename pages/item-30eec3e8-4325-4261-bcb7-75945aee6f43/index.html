Static publish

A HAX site is plain files, so any static host can serve it. These are free to start and work with one command from the site's folder.

Where to publish a HAX site for free
HostHow
Surgehax site site:surge --domain my-site.surge.sh
Vercelhax site site:vercel
Netlifyhax site site:netlify
GitHub PagesPush the site to a GitHub repository, run npm run ghpages:build, and turn on Pages for the repository.

No command line yet? Start the site at browser.hax.cloud, then publish the folder it saved.

Self-host

Run HAX on your own server, with editing and publishing included. Pick the backend your server already speaks. Both save the same files, so a site can move between them.

Any server that runs Node. The HAX command line tool uses this same backend.

Apache or nginx with PHP, including shared hosting.

Want it on your own computer first? Install the HAX command line tool and run hax serve, as shown on Get started.
